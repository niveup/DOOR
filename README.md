# DOOR / Jujum AI

A personal AI study copilot for GATE Mechanical + PSU preparation: daily routine
planning, journaling with mentor feedback, progress tracking, concept explainer,
mock interviews, and a personal finance module. Single-user by design — see
[PRD.md](PRD.md) v3.1 for scope and bets.

## Topology (three deployables + vendor store)

| Surface | Host | What it does |
|---|---|---|
| `frontend/` (Next.js) | Vercel | Web UI + authenticated `/api/backend` relay |
| `backend/` (Express gateway) | Render | All API routes, AI orchestration, cron tick |
| `mobile/` (Expo RN) | device | Native client hitting Express directly |
| `cloudflare/journal-store/` (Worker) | Cloudflare | Encrypted private-journal + tracker mirror + backups (D1) |

Database: Postgres (Supabase) via Prisma · Private journal: AES-GCM ciphertext in D1.

## Quick start

```bash
# backend (port 4000, internal API 4001)
cd backend && npm install && npm run prisma:generate && npm run dev

# frontend (port 3000)
cd frontend && npm install && npm run dev

# mobile
cd mobile && npm install && npx expo start
```

Environment contracts live in each package's `.env.example`; deployment steps in
[RENDER_DEPLOYMENT.md](RENDER_DEPLOYMENT.md) and [VERCEL_DEPLOYMENT.md](VERCEL_DEPLOYMENT.md).
